--- Full description (max 4000) ---
NetCarve is a fast, precise, fully offline subnet and CIDR calculator built
for network engineers, cloud architects, and DevOps teams. It performs all
IPv4 and IPv6 address math directly on your device using exact binary
arithmetic - no internet connection is ever required.

Designed for secure environments, NetCarve requests no internet permission,
contains no advertising, and includes no analytics or tracking. It works in
air-gapped data centres and restricted facilities where network access is
unavailable or not allowed.

WHY NETCARVE
- Completely offline: zero network requests, no INTERNET permission.
- No ads and no trackers: no advertising SDKs, no analytics, no telemetry.
- Exact math: every value is derived from integer bit operations, correct
  for every prefix length.
- Engineer-first design: instant on-keystroke results and copy-to-clipboard
  on every value.
- Free and lightweight.

IPV4 SUBNET CALCULATOR
- Enter an IPv4 address or full CIDR notation, such as 10.20.30.40/20.
- Instant results: network address, broadcast address, subnet mask,
  wildcard mask, first and last usable host, gateway, and total and usable
  host counts.
- Correct handling of special cases: /0, /31 point-to-point links (RFC 3021),
  and /32 host routes.
- Address classification: class A-E, private (RFC 1918), loopback,
  link-local, multicast, carrier-grade NAT (RFC 6598), documentation ranges,
  and reserved ranges.
- Binary, hexadecimal and reverse-DNS representations.
- Visual binary bit view that highlights network bits versus host bits.

VLSM PLANNER
- Equal split: divide a parent block into 2, 4, 8, 16... subnets.
- By hosts: allocate right-sized subnets from a list of host requirements,
  placed largest-first and size-aligned so no two blocks ever overlap.
- See block size, mask, usable range and host count for each allocation,
  plus remaining free addresses and utilisation.

IPV6 EXPLORER
- Parse full, compressed, and embedded-IPv4 forms such as
  ::ffff:192.168.1.1.
- Canonical compression with the longest zero run replaced by :: per
  RFC 5952, plus the fully expanded 128-bit form.
- Address-type classification: unspecified, loopback, link-local,
  unique local, multicast, documentation, and global unicast.
- Interactive prefix slider (/0 to /128) showing the block network and last
  address.

QUALITY OF LIFE
- Quick presets for common cloud and VPC blocks.
- Copy-to-clipboard on every value.
- Local history of saved blocks, stored only on your device.
- Dark, high-contrast interface that is easy to read in a data centre.

PRIVACY
NetCarve collects no personal data, uses no advertising or analytics, and
never connects to the internet. The optional history feature stores
calculations only in the app's private storage on your device and never
uploads them. Read the full privacy policy at the link on this listing.

Open source
NetCarve's complete, unminified source code is public under the MIT license,
as a demonstration of clean, well-tested, production-grade native software.
A "View our Clean Code on GitHub" link is available in the app's About
screen.
